# Live Demo Guide

1. Open `http://localhost:5173`.
2. The temporary local **Demo authority** account is selected automatically.
3. Enter an unused land ID, owner details, and area; select **Register land**.
4. Enter the demo buyer address already filled in; select **Request transfer**, then **Approve transfer**.
5. Select **Accept transfer**. The local demo automatically submits this final step from the buyer account.
6. Inspect the refreshed land details and the **Live session receipts** table.

The live receipts are from the local Hardhat chain. The saved comparison table is a reproducible benchmark snapshot, not Ethereum mainnet pricing.
